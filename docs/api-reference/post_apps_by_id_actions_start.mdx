title: "Start app"
description: "Start app through the Towbar API and MCP."
playground: simple
openapi: "/api-reference/openapi.json POST /apps/{appId}/actions/start"
---

MCP tool: `post_apps_by_id_actions_start`. Uses your current workspace permissions.

Supply an Idempotency-Key for this action. An accepted request may continue asynchronously; poll the returned ID.

See [request conventions](/docs/api/overview) and [automation workflows](/docs/api/workflows).
