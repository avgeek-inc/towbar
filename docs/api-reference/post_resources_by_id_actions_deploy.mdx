---
title: "Request resource deployment"
description: "Request resource deployment through the Towbar API and MCP."
playground: simple
openapi: "/api-reference/openapi.json POST /resources/{resourceId}/actions/deploy"
---

MCP tool: `post_resources_by_id_actions_deploy`. Uses your current workspace permissions.

Supply an Idempotency-Key for this action. An accepted request may continue asynchronously; poll the returned ID.

See [request conventions](/docs/api/overview) and [automation workflows](/docs/api/workflows).
