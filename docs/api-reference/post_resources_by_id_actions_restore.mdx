title: "Request resource restore"
description: "Request resource restore through the Towbar API and MCP."
playground: simple
openapi: "/api-reference/openapi.json POST /resources/{resourceId}/actions/restore"
---

MCP tool: `post_resources_by_id_actions_restore`. Requires the workspace owner role.

Supply an Idempotency-Key for this action. An accepted request may continue asynchronously; poll the returned ID.

See [request conventions](/docs/api/overview) and [automation workflows](/docs/api/workflows).
