title: "Request orphan cleanup"
description: "Request orphan cleanup through the Towbar API and MCP."
playground: simple
openapi: "/api-reference/openapi.json POST /servers/{serverId}/actions/cleanup-orphans"
---

MCP tool: `post_servers_by_id_actions_cleanup_orphans`. Requires the workspace owner role.

Supply an Idempotency-Key for this action. An accepted request may continue asynchronously; poll the returned ID.

See [request conventions](/docs/api/overview) and [automation workflows](/docs/api/workflows).
