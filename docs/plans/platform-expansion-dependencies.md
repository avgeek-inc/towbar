## Production Temporal

Production Temporal now uses the official server/admin-tools 1.31.1 images pinned to the multiarch digests recorded in `docs/plans/platform-expansion-progress.md`. Upstream server/tools code is MIT; the images contain separately licensed OS and dependency components. Both publish Linux amd64/arm64; local execution exercised arm64. Schema updates use the upstream SQL tool without overwrite/reset, and a read-only dynamic configuration keeps upstream defaults. The production gate proves repeat initialization and PostgreSQL-backed workflow recovery after server recreation. The existing matched TypeScript SDK family is unchanged. Update these pins together, review upstream schema compatibility, and repeat the production recovery gate; never replace this production backend with the ephemeral development server.
