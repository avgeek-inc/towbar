<Info>
  Towbar is an open source, operator-run product under active development.
</Info>

This page reports the project's stage, not the health of an individual Towbar
installation. Operators can use the installation's API and web health endpoints,
the **System health** screen, deployment history, and configured notifications
to monitor their own control plane and deployment targets.

Release notes and known changes are published in the
[changelog](https://github.com/avgeek-inc/towbar/blob/main/CHANGELOG.md).
