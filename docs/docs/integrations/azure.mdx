---
title: "Azure"
description: "Enable one runtime service principal for Azure Blob Storage backups and restores."
---

Create a Microsoft Entra service principal with Blob data access scoped to the required storage account and container. Add this to `/etc/towbar/towbar.yml`:

```yaml title="/etc/towbar/towbar.yml"
integrations:
  azure:
    enabled: true
    storageAccount: example
    container: towbar-backups
    prefix: towbar
    tenantId: <tenant-id>
    clientId: <client-id>
    clientSecret: <client-secret>
```

Validate and restart Towbar. Azure Blob Storage appears only when every enabled value is valid. The UI never returns the service-principal secret. Confirm permissions with a real [resource backup and restore](/docs/backups). Rotate the secret in `towbar.yml`, restart Towbar, verify an operation, and then revoke the previous secret.
