Cloudflare can manage owned DNS records and tunnel ingress.

## Cloudflare

```yaml title="/etc/towbar/towbar.yml"
integrations:
  cloudflare:
    enabled: true
    accountId: <account-id>
    zoneId: <optional-zone-id>
    apiToken: <scoped-account-token>
    cloudflaredImage: <reviewed-image-and-digest>
```

Use an account API token restricted to the zones and DNS operations Towbar
owns. `integrations.cloudflare.zoneId` is optional when the token can discover the
required zones. The cloudflared image must use Towbar's reviewed pinned image.
Continue with [Domains and TLS](/docs/domains-tls#cloudflare-tls) for DNS mode,
tunnel ingress, and ownership boundaries.
