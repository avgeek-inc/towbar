The public demo at [try.towbar.dev](https://try.towbar.dev) shows the current
Towbar dashboard with example repositories, Services, Datastores, servers, and
deployment history. Choose **Start demo** to open a ten-minute demo. You do
not need an account.

## Things to try

1. Open **Services**, choose **Example Website**, and deploy it. Watch a
   simulated deployment progress from queued to succeeded.
2. Open a service’s **Secrets** settings. Reveal a sample value, edit it, and
   save. These values belong only to your demo.
3. Run a scheduled job, stop and start a service, create a datastore backup,
   or restore one of the sample backups.
4. Explore the server providers and hardware, rename a server, or try its
   preparation and monitoring controls.
5. Try a notification destination, connect a sample repository, or edit the
   sample team. Notification tests and connection flows are simulated.
6. Pause automatic deployments for an example service, then use **Reset demo**
   to return to the original data.

Open **Example Website → Analytics** to explore sample HTTP traffic and website
pageviews. Switch the measure to **Pageviews** to see viewing time and bounce
rate, then scroll down to exit pages and outbound websites. Use **Filters** to
combine a path with a country, city, browser, or referring website. The results
are example data, not measurements from visitors to the demo.

All operations use sample data and are simulated. No servers are contacted,
notifications sent, or external accounts connected. Sample secret values and
credentials can be viewed and edited. Use only made-up values; do not enter
personal information or real secrets. Live terminals and account sign-in or
security enrollment are unavailable.

## Your session

The notice above the dashboard shows the time remaining. After ten minutes,
your demo ends and its changes reset. Start another demo to keep
exploring. **Reset demo** starts fresh immediately; **End demo** and sign-out
end the session.

Tabs in the same browser share a demo. Other browsers and visitors have
separate demos, including people using the same internet connection.
The demo can also reset during maintenance. If the demo is busy or asks you to wait,
try again in a few minutes.

To connect real repositories and servers,
[install your own Towbar instance](/docs/self-hosting/installation).
