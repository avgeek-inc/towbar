---
title: "Workload secrets"
description: "Declare required keys in Git and save their values on each app or resource."
---

Declare secret **names**, not values, in an entity manifest. Apps can use four stages; resources use runtime only:

```yaml title=".towbar/apps/api.app.yml"
secrets:
  build:
    - PACKAGE_TOKEN
  runtime:
    - DATABASE_URL
    - API_TOKEN
  preDeploy:
    - MIGRATION_TOKEN
  postDeploy: []
```

Sync the repository, open the app's **Settings → Secrets**, choose the environment and stage, then enter the values. For a resource, use **Resource → Settings → Secrets**. A new declaration starts unset. A missing required value blocks deployment but does not block sync. Existing values survive a successful sync while their names remain declared; removing a name deletes its saved value in the synced environment.

Values are stage-specific. Build secrets are available to supported builders during image construction, runtime secrets go to the running container, and hook secrets are available only to configured pre- or post-deploy hooks. Preview app values use an isolated preview scope and do not fall back to a persistent environment.

## Edit without exposing a stored value

**Form** shows one key per row. Stored values remain masked until an authorized Admin reveals them with the eye icon. Reveal before editing a masked value; an untouched field preserves the stored value. New unset fields can be filled directly. The **Editor** tab lets an Admin edit a stage as `KEY=value` lines after revealing that scope. It accepts quoted values, comments, multiline quoted strings, and optional `export` prefixes. Duplicate keys and invalid syntax must be fixed before saving.

```text
DATABASE_URL="postgres://user:password@postgres:5432/app"
API_TOKEN="{{globals.API_TOKEN}}"
```

The second line uses a [shared secret](/docs/secrets/shared); it stores the reference expression and resolves the value only for execution. Hovering over a `{{globals.KEY}}` expression can reveal its shared value to an authorized Admin. Hovering over a key name never reveals a value.

**Save** changes storage but does not restart a container or queue a deployment. Deploy the affected app or resource when ready. A stale edit returns a conflict; refresh and reapply it. Rotation of an application value does not change credentials inside an already-running database. Rotate the database credential itself before replacing its Towbar value and deploying consumers.
