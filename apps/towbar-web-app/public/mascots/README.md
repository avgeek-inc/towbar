# Towbar mascot artwork

The dashboard uses the same yellow bird as Scout and the existing error screens.
Services, Datastores and Servers were generated with the built-in image-generation
tool using `../scout/mascot.webp` as the character reference. The files are
384-pixel WebP assets with a transparent alpha channel.

The incident cards reuse `happy.png` and `../scout/mascot-worried.png`. Product
logos and provider icons keep their original artwork.
