# Browser logos

Chrome, Firefox, Edge, and Safari use unchanged SVGs from [Dashboard Icons](https://github.com/homarr-labs/dashboard-icons/tree/f651f5798c7d58bff3cff4d3a9c4645d87657bbd/svg), Apache-2.0. The collection license is included in [LICENSE-dashboard-icons](../resource-logos/LICENSE-dashboard-icons).

Vector artwork keeps the analytics icons sharp on dense displays and when the page is zoomed. Product names and marks belong to their respective owners and do not imply endorsement.
