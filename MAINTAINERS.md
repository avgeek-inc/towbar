# Maintainers

Towbar is authored by **Avgeek, Inc.**

The lead maintainer is
[Praveen Thirumurugan (@praveentcom)](https://github.com/praveentcom).

The maintainer reviews pull requests, coordinates releases, and makes final
decisions when community consensus is unclear. Contributors are encouraged to
open an issue before undertaking a large architectural change. Security reports
must follow [SECURITY.md](SECURITY.md) instead of using a public issue.

Maintainer changes are recorded through a pull request updating this file and
`.github/CODEOWNERS`.
